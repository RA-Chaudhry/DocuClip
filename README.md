# DocuClip - AI Video Intelligence & Viral Clip Generator

DocuClip is an automated, AI-powered video intelligence pipeline designed to extract high-engagement, viral clips from YouTube videos and local video uploads.

## Features
- **7-Factor Virality Engine:** Combines Hook ML classification, Emotional spikes, Curiosity gaps, Audio cadence/RMS energy, Computer Vision dynamics, Retention drop-off curves, and Rewatchability resolution loops.
- **Computer Vision Signal Analysis:** Frame-by-frame histogram scene cuts, motion differencing, and face presence detection.
- **Flexible Timing & Context Integrity:** Eliminates mid-sentence cut-offs using Whisper sentence alignment and dynamic RAG chunking.
- **Multi-Source Ingestion:** Supports YouTube / Online video URLs and direct local video file uploads.
- **Unified Microservices Architecture:** FastAPI, Celery, Redis, and Faster-Whisper.
